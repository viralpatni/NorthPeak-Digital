# Performance Optimizations

### Image Optimization
- Optimized image assets used throughout the website.
- Removed unnecessary placeholder graphics.
- Used responsive image sizing where appropriate to reduce page weight.

### Code Optimization
- Removed unnecessary rendering work.
- Eliminated unused components and redundant code.
- Kept JavaScript lightweight to improve load performance.

### Animation Optimization
- Removed excessive animations that could affect rendering performance.
- Retained only subtle hover effects and essential UI transitions.
- Reduced unnecessary motion to improve responsiveness.

### Asset Loading
- Optimized asset loading for a faster initial page render.
- Verified performance using Lighthouse in a clean browser session (Incognito Mode).

# Key Design Decisions

### Minimal Animations
Animations were intentionally kept subtle to improve usability and maintain strong Lighthouse performance.

### Editorial Layout
Instead of a template-style landing page, the website follows an editorial layout with varied sections to create a more premium and believable agency experience.

### Performance First
Performance was treated as a primary design constraint by minimizing unnecessary effects and keeping the overall interface lightweight.
