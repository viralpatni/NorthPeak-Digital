# AI Usage Disclosure

AI-assisted tools were used throughout this project to accelerate ideation and improve development quality.

## Tools Used

### Antigravity
Antigravity was used as an AI-assisted coding tool to help generate and refine the website structure, UI components, styling, and overall implementation. Its output was reviewed and iteratively refined throughout the development process.

### ChatGPT
ChatGPT was used as a development assistant for:

- Brainstorming design ideas and website structure
- Refining the visual design and user experience
- Improving copywriting and content
- Reviewing responsiveness and accessibility
- Suggesting performance optimizations
- Identifying Lighthouse improvements
- Debugging implementation issues
- Reviewing the project before final submission

## My Contribution

The final website was not accepted as generated by AI.

I manually:
- Reviewed and refined the generated code.
- Customized the UI to create a unique visual identity for NorthPeak Digital.
- Modified layouts, sections, typography, and content.
- Improved responsiveness across different screen sizes.
- Fixed implementation issues and testing problems.
- Optimized the website to achieve strong Lighthouse scores.
- Integrated the required project-specific features and footer credit.
- Deployed the application on Vercel and managed the GitHub repository.

AI served as a development assistant and productivity tool, while the final implementation, design decisions, testing, optimization, and deployment were completed and verified manually.
